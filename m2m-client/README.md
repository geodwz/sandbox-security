# m2m-client

Spring Boot OAuth 2.0 / OAuth 2.1 machine-to-machine client for sandbox-security. Uses `spring-boot-starter-security-oauth2-client` with a WebFlux-backed MVC stack and Spring Security's built-in OAuth 2. Resource Client support.

- Java 25
- Spring Boot 4.1.1

## Build and Run

```
mvn spring-boot:run
```
